A modern, high-performance, responsive portfolio website built with pure HTML5, modern CSS3 (Glassmorphism, CSS Grid, Flexbox), and Search Engine Optimization (SEO) best practices.

---

## ✨ Features

* **⚡ Ultra-Fast & Lightweight:** Built using vanilla web standards without heavy external JS framework overhead.
* **📱 Fully Responsive Layout:** Seamlessly scales from desktop monitors down to mobile viewports with a custom CSS-only navigation drawer.
* **🎯 Modern Bento-Grid UI:** Styled using sleek dark-mode glassmorphism cards and vibrant glowing gradient accents.
* **🔍 Search Engine Optimized (SEO):** Includes structured meta tags, Open Graph protocols, and robots control for Google search indexing.
* **💬 Integrated Contact Touchpoints:** Dedicated interaction cards linking directly to WhatsApp, GitHub, and Email platforms.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Native variables, Flexbox, CSS Grid, media queries, and glassmorphism styling.
* **FontAwesome v6:** Vector icon assets for platforms and stack utilities.
* **GitHub Pages:** Automated deployment pipeline.
